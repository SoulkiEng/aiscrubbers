# How to Remove Invisible ChatGPT Unicode Watermarks (`U+200B`, `U+202F`, `U+FEFF`)

When copying text from **ChatGPT, Claude, or Gemini** into resumes, academic portals, or Microsoft Word, hidden Unicode characters are frequently carried over:
- **Zero-Width Space (`U+200B`)**, **Zero-Width Non-Joiner (`U+200C`)**, **Zero-Width Joiner (`U+200D`)**, and **Byte Order Mark (`U+FEFF`)**
- **Narrow No-Break Space (`U+202F`)** and **Non-Breaking Space (`U+00A0`)**
- **Curly Smart Quotes (`“ ” ‘ ’`)** and dense **Em-Dash (`—`)** clusters

These non-keyboard control bytes can break keyword matching in **Workday, Greenhouse, and Taleo ATS** resume parsers and trigger automated formatting flags.
