## 🚀 Overview

**AIScrubbers** (`https://aiscrubbers.com`) is an open-architecture, local-first privacy and context-preparation studio engineered for the 2026 AI workflow ecosystem. All binary parsing, pixel reconstruction, Unicode sanitization, and multi-file RAG bundling execute **100% inside the user's browser RAM**.

### Core Capabilities (16 Local Tools)

1. **[C2PA & AI Metadata Remover](https://aiscrubbers.com/c2pa-remover/)**: Strip C2PA Content Credentials, JUMBF boxes, IPTC `trainedAlgorithmicMedia` tags, and embedded Midjourney/DALL-E/ComfyUI chunks from JPG, PNG, and WebP files.
2. **[C2PA & AI Provenance Inspector](https://aiscrubbers.com/c2pa-viewer/)**: Forensically inspect images and PDFs for hidden C2PA manifests, SynthID tags, and PNG `tEXt`/`iTXt` prompt graphs.
3. **[Deep EXIF, GPS & Serial Stripper](https://aiscrubbers.com/exif-scrubber/)**: Bulk-remove GPS coordinates, camera serial numbers, and XMP packets.
4. **[AI Image 300 DPI Print Normalizer](https://aiscrubbers.com/ai-image-normalizer/)**: Inject true binary 300 DPI JFIF/pHYs headers into 72 DPI Midjourney/DALL-E artwork for Amazon KDP and Etsy.
5. **[ChatGPT Invisible Watermark Cleaner](https://aiscrubbers.com/chatgpt-watermark-remover/)**: Detect and remove zero-width Unicode characters (`U+200B`, `U+FEFF`, `U+202F`), smart quotes, and AI em-dash spikes.
6. **[Clean ChatGPT Formatting for Word & Docs](https://aiscrubbers.com/ai-text-to-word-cleaner/)**: Strip Markdown asterisks (`**`), hash headers (`###`), and grey clipboard backgrounds for clean paste into Microsoft Word and Google Docs.
7. **[Prompt Privacy Scrubber (PII Redactor)](https://aiscrubbers.com/prompt-pii-redactor/)**: Tokenize sensitive names, emails, SSNs, phones, and API keys into reversible placeholders (`[EMAIL_1]`, `[API_KEY_1]`) before prompting ChatGPT or Claude, with 1-click local de-anonymization.
8. **[AI Cliché & Footprint Polisher](https://aiscrubbers.com/ai-burstiness-polisher/)**: Replace overused LLM vocabulary (*"delve", "tapestry", "testament", "moreover"*) and measure sentence burstiness.
9. **[NotebookLM & Claude 100+ File Merger](https://aiscrubbers.com/notebooklm-file-merger/)**: Combine 100+ PDFs, Word docs, Markdown, CSV, and code files into 1 XML-indexed Master File to bypass Google NotebookLM's 50-source limit and Claude's 20-file cap.
10. **[ChatGPT Export (`conversations.json`) Viewer to PDF](https://aiscrubbers.com/chatgpt-export-converter/)**: Open OpenAI data export ZIP or `conversations.json` files locally and export chat threads to searchable PDF or Markdown.
11. **[PDF & Word to Clean LLM Markdown](https://aiscrubbers.com/doc-to-llm-markdown/)**: Convert documents into token-compressed Markdown that saves 45–65% of context window tokens.
12. **[LLM Token Counter, Chunker & Cost Calculator](https://aiscrubbers.com/llm-token-calculator/)**: Compare token counts and API pricing across GPT-4o, o3-mini, Claude 3.7 Sonnet, Gemini 2.5 Pro, and DeepSeek R1.
13. **[`llms.txt` & `llms-full.txt` Generator](https://aiscrubbers.com/llms-txt-generator/)**: Build official `llmstxt.org` compliant indexes so ChatGPT Search, Perplexity, and Claude cite your website.
14. **[AI Crawler `robots.txt` Configurator](https://aiscrubbers.com/ai-robots-txt-generator/)**: Allow AI search bots (`OAI-SearchBot`, `PerplexityBot`) while blocking training scrapers (`CCBot`, `GPTBot`).
15. **[CSV / JSON to Fine-Tuning (`.jsonl`) Builder](https://aiscrubbers.com/jsonl-dataset-converter/)**: Convert spreadsheets into validated OpenAI ChatML JSONL datasets.
16. **[MCP Server Config (`mcp.json`) Builder](https://aiscrubbers.com/mcp-config-generator/)**: Visual builder for Claude Desktop and Cursor MCP configs (fixes Windows `npx.cmd ENOENT`).
