## 2. Detailed Store Description
AIScrubbers gives creators, researchers, and enterprise teams instant browser tools to sanitize AI text, redact sensitive prompt data, strip C2PA image metadata, and combine files for Google NotebookLM and Claude Projects.

Key Features Included in Popup:
- Instant Invisible Unicode Watermark Cleaner: Removes hidden zero-width characters (U+200B, U+FEFF, U+202F), smart quotes, and AI em-dash patterns directly in the popup and copies clean text to your clipboard.
- 1-Click Prompt PII Scrubber: Replaces email addresses, SSNs, and API keys with safe placeholders before you paste confidential text into ChatGPT or Claude.
- Direct Launchers for C2PA Content Credentials Remover, NotebookLM 100+ File Merger, ChatGPT-to-Word Formatter, and OpenAI conversations.json Viewer.

100% Local Privacy:
Every action runs locally inside your browser. Zero files or text strings are ever transmitted to external servers.
